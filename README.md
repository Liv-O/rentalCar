# RentalCar

RentalCar is a modern car rental web application built with Next.js.  
Users can browse available cars, filter them by different parameters, and view detailed information about each vehicle.

## Features

- Car catalog with pagination
- Filtering by:
  - brand
  - rental price
  - mileage
- Detailed car page
- Booking form with validation
- Loading, error, and not-found pages
- Responsive layout
- SSR + React Query hydration

## Tech Stack

- Next.js 15 / App Router
- TypeScript
- React Query
- Axios
- Formik + Yup
- CSS Modules
- React Hot Toast
- React Icons
